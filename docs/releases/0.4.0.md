### Improvements
- Added Obsidian's native Bases filter editor to view settings, including property pickers, nested groups, and advanced formulas. Enable the Bases core plugin to edit rules; existing rules continue to work without automatic migration.
- Added an Add note content button above the HTML editor, with guidance for showing the note body alongside a custom layout without writing template syntax (#17).
- Added a per-view Show navigation bar setting and kept the navigation bar consistent between reading view and live preview.
- Improved note switching by retaining the previous custom view until the next view is ready, reusing the live editor, and cancelling obsolete renders.
- Improved settings responsiveness, template property completion, editor accessibility, and dialog cleanup.
- Added a movie palette loader example that caches extracted colors and avoids the blue background flash while images load.

### Bug Fixes
- Fixed flashes of the native Markdown view during custom-view navigation, including rapid note switching.
- Fixed legacy filter conversion for list membership, missing values, checkbox properties, case-sensitive text matching, and numeric comparisons.
- Fixed stale custom views when referenced notes change, are renamed, are deleted, or become available.
- Fixed derived body values using stale content while editing and unnecessary replacement of the live editor.
- Fixed settings saves racing across edits and plugin reloads, and preserved malformed configuration for recovery.
- Fixed obsolete Canvas renders and restored normal nodes when custom views are disabled or Markdown attachments are removed.
- Fixed expression short-circuiting and conditional branches evaluating values that were not selected.
- Fixed Obsidian lint compatibility and updated nanoid to 5.1.16 and fast-uri to 3.1.4 to address dependency advisories.

### Tests
- Added regression coverage for the note content button, template undo, reading-mode body rendering, and editable content placement.
- Expanded coverage for native filter conversion, navigation holds, linked-note refresh, settings persistence, Canvas cleanup, and expression evaluation.
- Added live Obsidian checks for native filter compatibility and custom-view navigation flicker.
