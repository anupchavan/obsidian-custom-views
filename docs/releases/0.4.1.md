### Improvements
- Added custom views in popover previews and embedded notes, with shared templates and optional HTML, CSS, and JavaScript overrides for each context.
- Reused Knap for filter-chain parsing and shared filters, while preserving Custom Views compatibility where behavior differs. Available filters are also included in editor suggestions.
- Reduced idle work by using embed, layout, and metadata events on supported Obsidian versions instead of polling every second.
- Reused parsed expressions across notes and loop iterations with a bounded syntax cache.
- Widened the template editor dialog while keeping native setting groups and responsive sizing.
- Removed the development-only movie palette template and migration from the plugin repository.

### Bug Fixes
- Fixed Canvas reading-mode requests unnecessarily removing an already-mounted custom view.
- Kept the previous embedded view visible while the live editor finishes mounting and measuring its layout.
- Fixed redundant embedded renders and prevented superseded render callbacks from resetting newer views.
- Refreshed embedded views when linked-note dependencies change.
- Fixed Escape closing the template dialog before dismissing editor completions or search.
- Updated test dependencies to address vulnerability advisories.

### Tests
- Added regressions for repeated Canvas mode requests, pending render coalescing, stale failures, and linked-note updates.
- Added Knap compatibility checks for typed filter results, regex alternation, and encoded HTML.
- Verified fuzzy matching and bold matched characters in the running editor using CodeMirror's existing completion support.
- Recorded Canvas transition samples, idle refresh counts, and repeated-expression parsing measurements.
